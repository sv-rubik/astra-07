# АСТРА • 07

Интерактивный мостик звездолёта на русском: живой радар, поворотные регуляторы энергии, переключатели, ракеты и гиперпереход по выбранным координатам.

## Как играть

Выберите координаты на звёздной карте, дождитесь заряда гипердвигателя и нажмите «Гиперпрыжок». Перетаскивайте регуляторы энергии вверх/вниз или крутите их колёсиком; сумма мощности всегда 100%. Для стрельбы выберите учебную цель, откройте защитную крышку и нажмите «Пуск».

Клавиши: **N** — карта, **J** — прыжок, **M** — звук, **Esc** — закрыть экран. Звук включается отдельно кнопкой ♫. Поддерживаются мышь, клавиатура и сенсорное управление.

## Запуск

Откройте `index.html` в браузере или используйте любой статический сервер. Сборка и установка зависимостей не нужны. Для GitHub Pages: **Settings → Pages → Deploy from a branch → main / (root)**.

## Что работает

- Процедурное звёздное небо и планеты, радар, выбор учебных целей и сканирование.
- Тяга, режимы двигателя, тангаж, крен, автопилот, щиты, стабилизация и маскировка.
- Общая энергетическая шина, которая влияет на скорость, щиты, оружие и заряд гипердвигателя.
- Три ракеты, одиночный пуск и залп, защитная крышка, видимый полёт и попадания, пополнение боезапаса.
- Пять систем на карте, ручной ввод координат, звёздные полосы и тоннель при переходе, новый сектор после выхода.
- Диагностика, моделируемая радиосвязь, журнал событий, аварийный стоп, звук и полный экран.
- Адаптивная компоновка и упрощённые эффекты при системной настройке уменьшения движения.

Состояние хранится в памяти браузера и сбрасывается при обновлении страницы. Все события — игровая симуляция. Шрифты загружаются с Google Fonts; без сети используются системные. Серверных функций и ключей нет.
